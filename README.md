# Full Stack Content Management System for Dynamic Blog and Web Page Creation

## Project Overview

This project is a full-stack Content Management System (CMS) designed to allow users to create, manage, edit, and publish blog posts and dynamic web pages through a user-friendly web interface.

The system aims to reduce the technical knowledge required for managing website content by providing an intuitive platform for content creation, page management, media handling, and publishing.

## Problem Statement

Many users and small organizations want to create and manage websites or blogs but may not have advanced programming knowledge.

Traditional website development often requires technical skills to create web pages, manage content, and publish updates.

This project proposes a Content Management System that provides an easy-to-use interface for creating and managing website content without requiring users to manually write or modify HTML code.

## Project Objectives

- Develop a full-stack Content Management System.
- Provide secure user registration and authentication.
- Allow users to create, edit, and delete blog posts.
- Provide a rich-text editor for content creation.
- Support image and media management.
- Allow users to create and manage dynamic web pages.
- Implement a drag-and-drop page-building feature.
- Store content securely in a database.
- Provide draft, preview, and publishing functionality.
- Provide search and category management.
- Develop a responsive and user-friendly interface.

## Target Users

### Admin / Blog Owner

The admin or blog owner will be able to:

- Register and log in.
- Create blog posts.
- Edit blog posts.
- Delete blog posts.
- Save posts as drafts.
- Publish and unpublish posts.
- Create and manage web pages.
- Upload media.
- Manage categories.
- Use the page builder.
- Manage website content through a dashboard.

### Website Visitors

Visitors will be able to:

- View the website homepage.
- Browse published blog posts.
- Search for blog posts.
- Read individual articles.
- View published web pages.
- Access images and other media content.
