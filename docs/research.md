# Existing CMS Research

## Introduction

Before developing the proposed Content Management System, existing CMS platforms were studied to understand common features, user workflows, and content management approaches.

## WordPress

WordPress is a widely used Content Management System that provides tools for creating and managing websites and blogs.

Important features studied include:

- Blog post creation
- Page management
- Media management
- Themes
- Plugins
- User management
- Publishing workflow
- Administrative dashboard

## Drupal

Drupal is another Content Management System that provides flexible content management capabilities.

Important features studied include:

- Content management
- User roles
- Content types
- Publishing
- Modular architecture
- Administration tools

## Features Selected for the Proposed System

Based on the study of existing CMS platforms, the following features were selected for the proposed project:

- User authentication
- Admin dashboard
- Blog post management
- Page management
- Rich-text editing
- Media management
- Categories
- Search
- Draft management
- Publishing workflow
- Drag-and-drop page builder

## Proposed Improvement

The proposed system will focus on providing a simple and student-developed CMS with essential content management features and an easy-to-use interface.

The system will combine blog management with dynamic page creation and a drag-and-drop page-building approach.

## Conclusion

The study of existing CMS platforms helped in understanding the basic requirements of a modern Content Management System. The findings will be used as a reference while designing and developing the proposed system.
